Step 3

Writing the Backend Checkout Endpoint in server.js

Alex writes an Express route (/api/create-checkout). Hover or click on the code lines below to see how Alex passes the secret key and specifies the allowed payment methods (gcash, paymaya, card, qrph).

server.js Hover over highlighted lines for deep explanations
const Paymongo = require('paymongo'); // Imports SDK installed via npm
const paymongo = new Paymongo(process.env.PAYMONGO_SECRET_KEY); // Authenticates server using secret key
app.post('/api/create-checkout', async (req, res) => {
const session = await paymongo.checkoutSessions.create({
  amount: 465000, // ₱4,650.00 in centavos
  currency: 'PHP',
  payment_method_types: ['gcash', 'paymaya', 'card', 'qrph'],
  description: 'Keychron Keyboard Purchase',
  success_url: 'https://alexstore.ph/success'
});
res.json({ checkoutUrl: session.checkout_url }); // Sends hosted payment link to user
});

Step 5

Order Fulfillment via Webhooks

Once the customer approves the payment in GCash or Maya, the gateway sends an automated HTTP POST payload (a Webhook) directly to Alex's server endpoint to update the order database automatically.

webhook-listener.js Alex's Server Endpoint 
app.post('/api/webhooks', (req, res) => {
  const event = req.body.data;

  if (event.attributes.type === 'payment.paid') {
    const orderId = event.attributes.data.id;
    markOrderAsPaidInDatabase(orderId);
    sendConfirmationEmail();
  }

  res.status(200).send({ received: true });
});
